# 🚢 Fleet IT Report System

Sistem manajemen dan pelaporan operasional IT terpusat untuk armada kapal. Aplikasi ini dibangun untuk menggantikan pelaporan manual menjadi sistem berbasis web yang lebih efisien, terstruktur, dan mudah dipantau.

## 🚀 Teknologi yang Digunakan

- **Framework:** Laravel 11 (PHP)
- **Frontend:** Tailwind CSS & Flowbite
- **Database:** MariaDB / MySQL
- **Local Environment:** Laragon

## 📋 Ruang Lingkup Sistem (Scope of Work)

Sistem ini melacak dan mengelola pelaporan mingguan untuk beberapa kapal dalam armada, dengan fokus pada metrik berikut:
- **CCTV:** Status ketersediaan dan perekaman.
- **Network (Jaringan):** Kestabilan koneksi, *uptime/downtime* (VSAT/Starlink), dan *routing*.
- **User Support:** Pencatatan kendala *user* (kru kapal) dan penyelesaiannya.
- **Security:** Audit keamanan jaringan dan kepatuhan sistem.
- **Backup System:** Status *backup* data esensial di setiap kapal.
